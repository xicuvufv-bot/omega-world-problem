# AgentFlow — AI Agent Micropayment Network

**Fuse: Millicent (1995) broker scrip + Stablecoins + AI Agents**

---

## What Is This?

AgentFlow is a micropayment network for AI agents, built by fusing a forgotten 1995 economic mechanism (broker scrip) with modern technology (stablecoins, x402, AI agents).

**The Problem**: AI agents make hundreds of API calls daily. Stripe charges $0.30 + 2.9% per transaction. 100 calls = $30+ in fees.

**The Solution**: AgentFlow's x402 broker handles batch settlement at $0.001 per transaction. 100 calls = $0.10 total.

**The Savings**: 1000x cheaper.

---

## How It Works

```
1. Agent purchases scrip in bulk (amortizes credit card cost)
   └─> Inspired by Millicent (1995) broker scrip model

2. Agent spends scrip at providers (sub-cent transactions)
   └─> Powered by stablecoins (USDC/USDT)

3. Broker settles in batches (reduces overhead)
   └─> Uses x402 protocol (HTTP 402)
```
