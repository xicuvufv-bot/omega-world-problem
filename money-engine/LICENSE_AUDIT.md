### What You MUST Do
- If using GPLv3 tools in distributed software, share source
- Follow each bug bounty program's rules

- Report vulnerabilities responsibly

### What You CANNOT Do
- Test systems without authorization

- Most tools are permissive (MIT, Apache, BSD)
- GPLv3 tools require source sharing if distributed
- Your custom pipeline code is your IP
- Findings belong to you (check program terms)
- Revenue from bounties is taxable income

- [ ] All testing within authorized scope
- [ ] Responsible disclosure for all findings
- [ ] No unauthorized data access
- [ ] Tax reporting for all earnings
- [ ] License compliance for distributed code
- [ ] Exchange terms of service compliance
