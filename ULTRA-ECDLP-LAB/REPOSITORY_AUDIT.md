## 4. Runtime-file dependency check

Every file the release needs at build/test/run time for the CPU path is tracked:
`v4_cpu_engine.cpp` (builds), `challenges.json`, `test_*.py`, `build.py`,
`kaggle_v5_run.py`, `detect_env.py`, `challenge70.py`. Nothing required is
untracked or ignored. Scratch `_t*`/`_v5_pipeline.log` are excluded by design
(never required).

## 5. Security / synthetic-only

- No real Bitcoin puzzle, no real private key anywhere. `challenge70.py` derives
  `k` from `SHA256(seed)`, forces bit `bits-1`, masks to `bits`.
- The independent verifier confirms `k ∈ [2^69, 2^70)` and `k·G == Q` for all 10
  instances in the sealed `challenges.json`.
- No credentials, secrets, or API tokens in the tree.
