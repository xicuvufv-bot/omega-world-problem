## Key Patterns Discovered

### Why Projects Die (Not Technical Failure)
1. **Ecosystem shift**: Python DSP → PyTorch killed pyo
2. **Framework war**: Caffe2 → PyTorch killed Detectron v1
3. **Single maintainer**: Most abandoned projects have 1-2 developers
4. **License restrictions**: GPL/CC-BY-NC limits adoption
5. **API complexity**: audioFlux is harder to use than librosa
6. **Runtime dependency**: PhantomJS death killed Nightmare, PhantomCSS

### The Hidden Opportunity Pattern
```
PROVEN ALGORITHM (old)
+ DEAD ECOSYSTEM (fixed)
+ MODERN UI/API (new)
+ CLEAR DEMAND (existing)
= MONEY
```
