## Key Discoveries Timeline

### Discovery 1: RYS Layer Duplication (March 2025)
- **Source**: David Noel Ng's blog + GitHub
- **What**: Duplicating specific transformer layers boosts reasoning 17-23%
- **Status**: Working, proven, #1 on HuggingFace Leaderboard
- **Gap**: Not commercialized, remains a community experiment

### Discovery 2: LLM Circuit Finder (March 2026)
- **Source**: GitHub (alainnothere)
- **What**: Automated circuit detection + pruning + duplication
- **Status**: Working, tested on 7 models
- **Gap**: Research tool, not a service

### Discovery 3: layer-scan (April 2026)
- **Source**: PyPI
- **What**: Automated (i,j) scanning with visualization
- **Status**: Beta, actively maintained
- **Gap**: CLI tool, not a service

### Discovery 4: Model Surgery (2026)
- **Source**: model-surgery.com
- **What**: Knowledge transplantation between models
- **Status**: Commercial product
- **Gap**: Different capability (transfer vs enhancement)

### Discovery 5: hoof.ai (2026)
- **Source**: hoofai.com
- **What**: Task-specific model pruning
- **Status**: Commercial product
- **Gap**: Only pruning, no reasoning enhancement

### Discovery 6: ADATE (1990s, archived)
- **Source**: GitHub (tranchau989)
- **What**: Automatic algorithm generation via evolution
- **Status**: Historical, requires 32-bit OS
- **Gap**: Could be modernized with LLM fitness evaluation

### Discovery 7: ROBACUS (1970s-80s, archived)
- **Source**: GitHub (tcveatch)
- **What**: Algorithm generation by questioning
- **Status**: Historical, requires Fortran toolchain
- **Gap**: Could be modernized with LLM interface

### Discovery 8: LegacyLens (2026)
- **Source**: GitHub (yashkuceriya)

- **Gap**: Only Fortran, could extend to other languages

### Discovery 9: OptiLLM (2024)

- **Gap**: Prompt-level only, doesn't change model

### Discovery 10: EURISKO (1980s, archived)

- **Status**: Source recovered, running in Interlisp
