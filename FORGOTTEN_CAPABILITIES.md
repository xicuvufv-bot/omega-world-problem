# FORGOTTEN_CAPABILITIES.md - Hidden Powers in Old Code

## 1. RYS Layer Duplication
**Found in**: dnhkng/RYS (2025)
**Capability**: Boost LLM reasoning 17-23% by duplicating specific layers
**Why forgotten**: Community experiment, never commercialized
**Modern value**: HUGE - $1.9B fine-tuning market could be disrupted

## 2. ADATE Algorithm Synthesis
**Found in**: tranchau989/ADATE (1990s)
**Capability**: Automatically generate novel algorithms via evolution
**Why forgotten**: Requires 32-bit OS, SML/NJ, arcane build process
**Modern value**: HIGH - could be combined with LLM fitness evaluation

## 3. EURISKO Discovery Engine
**Found in**: white-flame/eurisko (1981)
**Capability**: Autonomous concept discovery in knowledge spaces
**Why forgotten**: Locked behind password until Lenat's death, Interlisp required
**Modern value**: MEDIUM - could inform modern AI discovery systems

## 4. ROBACUS Problem Decomposition
**Found in**: tcveatch/robacus (1970s)
**Capability**: Generate algorithms by asking structured questions
**Why forgotten**: Fortran codebase, no documentation
**Modern value**: HIGH - question-driven problem solving is still rare

## 5. Quantum Compression
**Found in**: UnQuantum project (2026)
**Capability**: LZ77 + arithmetic coding with strong compression ratios
**Why forgotten**: DOS-only tool, Borland DPMI dependency
**Modern value**: MEDIUM - niche but useful for legacy data

## 6. ET++ Framework
**Found in**: redporter/ETPlusPlus (1991)
**Capability**: Window-system-independent application framework with reflection
**Why forgotten**: C++ 2.0 era, ahead of its time
**Modern value**: LOW - modern frameworks have superseded it

## 7. Signalnine CMS
**Found in**: Matt Michie's blog (2002)
**Capability**: Widget-based layout, content federation (ActivityPub precursor)
**Why forgotten**: WordPress won with simplicity
**Modern value**: MEDIUM - federation concept is now mainstream (Mastodon)

## Common Pattern
These projects were forgotten not because they were bad, but because:
1. **Timing**: Too early for their market (Signalnine, EURISKO)
2. **Complexity**: Required expertise that wasn't widely available (ADATE, ROBACUS)
3. **Platform**: Tied to obsolete platforms (DOS, Interlisp, Fortran)
4. **Simplicity**: Lost to simpler alternatives (Signalnine → WordPress)

**The opportunity**: Modernize the good ideas with modern tooling and interfaces.
