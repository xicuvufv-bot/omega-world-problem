# FALSE POSITIVES - Things That Look Like Money But Aren't Claimable

**Research Date**: July 7, 2026  
**Purpose**: Document opportunities that appeared promising but turned out to be false, expired, or inaccessible

---

## 1. EXPIRED AIRDROPS

### 1.1 Uniswap UNI Distribution (2020)
**Why it looked real**: 400 UNI distributed to every address that used Uniswap before Sep 2020  
**Reality**: Claim deadline passed. Unclaimed tokens returned to governance treasury  
**Lesson**: Most airdrops have strict deadlines

### 1.2 ENS Genesis Distribution (2021)
**Why it looked real**: 25M ENS distributed to historical users  
**Reality**: Claim deadline was May 2022. Unclaimed tokens returned to DAO  
**Lesson**: DAO airdrops almost always have expiry dates

### 1.3 Optimism OP Airdrop 1 (2022)
**Why it looked real**: 5% of total supply to early users  
**Reality**: Claim deadline passed. Later rounds had separate criteria  
**Lesson**: Check for subsequent rounds before giving up

## 2. SCAM/PHISHING OPPORTUNITIES

### 2.1 "Claim Your Tokens" DMs
**Why it looks real**: Messages claiming you have unclaimed tokens  
**Reality**: 100% phishing. Never click links from DMs  
**Red flag**: Urgency, "limited time", require wallet connection  
**Evidence Score**: 0/5

### 2.2 Fake Airdrop Websites
**Why it looks real**: Professional-looking sites mimicking real projects  
**Reality**: Drain wallet upon "claim" transaction  
**Red flag**: URLs that are slight misspellings of real domains  
**Evidence Score**: 0/5

### 2.3 "Send ETH to Receive More" Scams
**Why it looks real**: "Send 1 ETH, receive 10 ETH back"  
**Reality**: Simple theft. No legitimate project does this  
**Red flag**: Any request to send funds first  
**Evidence Score**: 0/5

## 3. GEOGRAPHIC RESTRICTIONS

### 3.1 US-Only Airdrops
**Why it looks real**: Major protocol launches  
**Reality**: Excluded jurisdictions list often includes non-US countries too  
**Example**: Some airdrops exclude US, China, and sanctioned countries  
**Algeria status**: Usually included, but verify per-project

### 3.2 KYC-Required Grants
**Why it looks real**: Open grant applications  
**Reality**: Require bank accounts, tax IDs, or entity registration  
**Algeria status**: May be difficult without local business entity

---

## 4. UNCLAIMABLE REWARDS

### 4.1 Governance Voting Rewards
**Why it looks real**: "Earn by voting"  
**Reality**: Requires token holdings to vote, rewards often vest locked  
**Example**: Compound COMP, Uniswap UNI governance  
**Lesson**: Need tokens first, rewards are marginal

### 4.2 Liquidity Mining Rewards (Expired)
**Why it looked real**: "Provide liquidity, earn tokens"  
**Reality**: Mining programs have end dates  
**Example**: SushiSwap onsen ended, Curve wars settled  
**Lesson**: Check if program is still active before depositing

### 4.3 Testnet Token Claims
**Why it looks real**: "Claim testnet tokens"  
**Reality**: Testnet tokens have no value  
**Example**: Sepolia ETH, Goerli ETH  
**Lesson**: Only useful for development, not for profit

---

## 5. ALREADY-CLAIMED OPPORTUNITIES

### 5.1 Gitcoin Passport Rewards
**Why it looked real**: "Verify identity, earn rewards"  
**Reality**: Rewards are GTC tokens, often fully distributed  
**Lesson**: Check current round allocation

### 5.2 Layer 2 Bridging Rewards
**Why it looked real**: "Bridge to L2, earn airdrop"  
**Reality**: Most L2 airdrops (OP, ARB) already distributed  
**Lesson**: First-mover advantage is gone for major L2s

---

## 6. FALSE BUG BOUNTY CLAIMS

### 6.1 Known/Already-Fixed Bugs
**Why it looks real**: Code vulnerability exists in older versions  
**Reality**: Already patched in production  
**Lesson**: Always check latest deployed version before reporting

### 6.2 Informational/Low-Severity Findings
**Why it looks real**: Code issue exists  
**Reality**: Below bounty threshold (gas optimization, style issues)  
**Lesson**: Focus on critical/high-severity impacts

### 6.3 Out-of-Scope Contracts
**Why it looks real**: Vulnerability in related contract  
**Reality**: Not in program scope  
**Lesson**: Read scope definitions carefully

---

## 7. HONEYPOT TOKENS

### 7.1 "Free" Token Distributions
**Why it looks real**: Tokens appear in wallet  
**Reality**: Cannot sell (honeypot) or huge tax to sell  
**Lesson**: If you didn't buy it or earn it legitimately, it's likely a scam

### 7.2 Unsolicited NFT Mints
**Why it looks real**: Free NFT in wallet  
**Reality**: Contains malicious approval request  
**Lesson**: Never interact with unsolicited NFTs

---

## SUMMARY: RED FLAGS TO WATCH FOR

| Red Flag | Action |
|----------|--------|
| Urgency ("act now!") | Stop, verify independently |
| Requires sending funds first | Scam, do not proceed |
| DMs with claim links | Phishing, ignore |
| Too-good-to-be-true returns | Almost always is |
| Unknown contract interactions | Check on Etherscan first |
| No official announcement | Likely fake |
| Pressure to share seed phrase | Scam, never do this |

---

## VERIFICATION CHECKLIST

Before acting on any opportunity:

- [ ] Is there an official announcement from the project's verified account?
- [ ] Does the URL match the official domain exactly?
- [ ] Are there multiple independent sources confirming this?
- [ ] Has the deadline passed?
- [ ] Is my jurisdiction eligible?
- [ ] Am I being asked to send funds?
- [ ] Does this require wallet connection to unknown contract?
