# TOP 5 FORGOTTEN MECHANISMS

## Selection Criteria
- Modularity (can be decomposed + recomposed)
- Original failure was due to missing modern component
- Modern components now exist
- Addresses current urgent problem
- Identifiable customer with willingness to pay
- Multi-tenant platform potential (not SaaS)

---

## #1 — MILLECENT BROKER SCRIP (1995)
**The forgotten**: Bulk scrip purchase amortizes credit card cost
**Original failure**: Users hated per-purchase decisions. Advertising won.
**Modern component**: Stablecoins + HTTP 402 + x402 protocol
**Current problem**: AI agents need sub-cent payments for API calls
**Customer**: AI agent builders (10,000+ startups)
**Value**: 1000x cheaper than Stripe for microtransactions

**Evidence chain**:
- Millicent 1995 paper → broker scrip concept
- BitGold 1996 → gold-backed digital tokens
- x402 2025 → HTTP 402 protocol for machine payments
- 2026: AI agent economy needs this exact mechanism

## #3 — HASHCASH PROOF-OF-WORK (1997)

**Original failure**: ASICs made anti-spam trivial

**Current problem**: AI agents spam APIs, no rate limiting
**Customer**: API providers (OpenAI, Anthropic, etc.)
**Value**: OpenAI loses millions to bot spam

**Evidence chain**:
- Hashcash 1997 → burn work for tokens
- Bitcoin 2009 → proved PoW creates value
- 2026: AI agents need rate limiting, not humans
- 2026: API spam costs millions monthly
