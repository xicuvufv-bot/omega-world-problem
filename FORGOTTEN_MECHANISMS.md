# FORGOTTEN MECHANISMS DATABASE

## Top 20 Forgotten Economic Mechanisms

### 1. MILLECENT BROKER SCRIP (1995-2004)
- **Mechanism**: Buy scrip from broker in bulk → spend at vendor in fractions of a cent
- **Innovation**: Amortized credit card overhead via bulk purchase
- **Failed because**: Advertising won. Users hated deciding per-purchase.
- **Modern relevance**: CRITICAL. AI agents don't have "decision friction."
- **Modern fusion**: Stablecoins + HTTP 402 + x402 protocol

### 2. MOJO NATION RESOURCE CURRENCY (2000-2002)
- **Mechanism**: Earn Mojo by contributing storage/bandwidth → spend Mojo to consume
- **Innovation**: Resource-denominated internal currency
- **Failed because**: Hyperinflation, bugs, no anti-inflation measures
- **Modern relevance**: HIGH. Filecoin/Arweave proved distributed storage works.
- **Modern fusion**: Stablecoin-backed resource tokens + automated pricing

### 3. DIGICASH/ECASH BLIND SIGNATURES (1989-1998)
- **Mechanism**: Bank signs tokens without seeing content → anonymous digital cash
- **Innovation**: Privacy-preserving payments
- **Failed because**: Merchant adoption chicken-and-egg
- **Modern relevance**: MEDIUM. Bitcoin solved decentralization. Zcash uses similar tech.
- **Modern fusion**: Already reinvented via cryptocurrency

### 4. HASHCASH PROOF-OF-WORK (1997)
- **Mechanism**: Burn CPU cycles to create tokens → anti-spam/anti-DoS
- **Innovation**: First virtual scarcity without central party
- **Failed as**: Anti-spam (ASICs made it trivial)
- **Succeeded as**: Bitcoin mining algorithm
- **Modern relevance**: HIGH. Original anti-spam purpose still useful for AI agents.
- **Modern fusion**: AI agent rate limiting + reputation scoring

### 5. PEPPERCOIN RANDOM SELECTION (2001-2007)
- **Mechanism**: Batch small purchases → randomly charge one in full
- **Innovation**: Reduced per-transaction cost from 27c to ~10c
- **Failed because**: Merchant adoption never reached volume
- **Modern relevance**: MEDIUM. Stablecoins reduce cost further.
- **Modern fusion**: Batch settlement for micropayment streams

### 6. PAYSWARM/BITMUNK (2009-2013)
- **Mechanism**: Browser-native open standard for digital goods
- **Innovation**: Web-native micropayments
- **Failed because**: Too early. No crypto wallets.
- **Modern relevance**: HIGH. Browser crypto wallets exist now.
- **Modern fusion**: HTTP 402 + browser wallets + stablecoins

### 7. HAWTHORNE EXCHANGE REPUTATION (1993)
- **Mechanism**: Trade reputation tokens in fixed-supply system
- **Innovation**: Quantified reputation
- **Failed because**: Tokens were worthless without grounding
- **Modern relevance**: HIGH. On-chain reputation is hot topic.
- **Modern fusion**: Reputation tokens backed by verifiable actions

### 8. MAGIC MONEY CUSTOM CURRENCIES (1994)
- **Mechanism**: Create custom digital currencies via toolkit
- **Innovation**: User-minted currencies
- **Failed because**: No network effect
- **Modern relevance**: MEDIUM. Stablecoins + token factories.
- **Modern fusion**: Programmable money with stablecoin backing

### 9. CYBERCOIN STORED VALUE (1996-2001)
- **Mechanism**: Stored-value digital wallet
- **Failed because**: Required proprietary client software
- **Modern relevance**: LOW. Solved by modern wallets.
- **Modern fusion**: Already reinvented

### 10. MONDEX SMART CARD (1993-2001)
- **Mechanism**: Smart-card electronic cash
- **Failed because**: Required physical hardware
- **Modern relevance**: LOW. NFC payments solved this.
- **Modern fusion**: Already reinvented

### 11. NETBILL (1997-2001)
- **Mechanism**: Distributed transaction system with authentication
- **Failed because**: Too complex for the era
- **Modern relevance**: MEDIUM. All components now exist.
- **Modern fusion**: Smart contracts + identity layer

### 12. BEENZ (1999-2001)
- **Mechanism**: Online loyalty currency
- **Failed because**: Unconvertible currency, no trust
- **Modern relevance**: MEDIUM. Stablecoins solve convertibility.
- **Modern fusion**: Loyalty tokens with stablecoin redemption

### 13. FLOOZ (1999-2001)
- **Mechanism**: Online gift currency
- **Failed because**: Russian money laundering scheme, 19% fraud
- **Modern relevance**: LOW. KYC/AML now required.
- **Modern fusion**: Regulated stablecoins

### 14. DIGITAL BAZAAR P2P COMMERCE (2009-2013)
- **Mechanism**: Open-source P2P buying/selling
- **Failed because**: No payment rail
- **Modern relevance**: MEDIUM. Crypto payments exist now.
- **Modern fusion**: DEX + P2P commerce

### 15. CENTIPAID APACHE MICROPAYMENTS (2012)
- **Mechanism**: Apache module for content micropayments
- **Failed because**: Server-side, no adoption
- **Modern relevance**: LOW. Client-side solutions better.
- **Modern fusion**: Browser-native payments

### 16. A2AGORA AGENT COMPUTE MARKET (2026)
- **Mechanism**: Agent-to-agent compute trading
- **Innovation**: Open marketplace for AI agent compute
- **Status**: Early draft
- **Modern relevance**: VERY HIGH. This IS the future.

### 17. AGENT BAZAAR (2026)
- **Mechanism**: RFQ-based agent task marketplace
- **Innovation**: Reputation-weighted quote matching
- **Status**: Hackathon MVP
- **Modern relevance**: VERY HIGH. Proves the model.

### 18. ZEPPELIN COMPUTING MARKETPLACE (2015)
- **Mechanism**: Decentralized marketplace for compute power
- **Failed because**: Too early for Ethereum ecosystem
- **Modern relevance**: HIGH. DePIN + AI compute demand.
- **Modern fusion**: GPU marketplace with stablecoin payments

### 19. IEXEC P2P BROKERING (2018-2020)
- **Mechanism**: Decentralized compute marketplace with escrow
- **Failed because**: Centralized order store
- **Modern relevance**: HIGH. P2P alternative exists.
- **Modern fusion**: Fully decentralized with smart contracts

### 20. DAZAAR HYPERCORE MARKETPLACE (2020)
- **Mechanism**: Marketplace for selling/buying hypercores
- **Innovation**: Custom payment validators
- **Status**: Minimal adoption
- **Modern relevance**: MEDIUM. Niche but novel.
- **Modern fusion**: Data marketplace with flexible payments
