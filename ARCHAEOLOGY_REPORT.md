## Research Methodology

### Phase 1: Source Identification
- Searched archive.org for 15+ forgotten payment protocols
- Analyzed Wikipedia "Digital currency" section history
- Reviewed academic papers on micropayment systems
- Studied failed cryptocurrency projects (2000-2013)
- Investigated pre-Bitcoin digital cash systems

### Phase 2: Mechanism Extraction
For each forgotten mechanism, extracted:
1. Core economic mechanism
2. Innovation that made it novel
3. Why it failed (missing component)
4. Whether the missing component now exists
5. Current problem it could solve

### Phase 3: Modularity Analysis
Evaluated each mechanism for:
- Decomposability (can parts be separated?)
- Recomposability (can parts be recombined?)
- Modern relevance (does it solve current problems?)
- Customer clarity (who would pay for this?)
- Value proposition (why now?)

### Phase 4: Fusion Construction
For top candidates:
1. Identify modern components that solve original failure
2. Map fusion graph (OLD → MECHANISM → MODERN → PROBLEM → CUSTOMER → VALUE)
3. Build economic model (revenue, pricing, unit economics)
4. Create MVP prototype
