## How to Customize

### Quick Start
1. Open any `.html` file in your favorite code editor (VS Code, Sublime Text, etc.)
2. Replace the placeholder text with your own content
3. Swap the colored placeholder divs with your images (`<img>` tags)
4. Update colors by modifying the CSS variables at the top of each file
5. Save and open in your browser to preview

### Customizing Colors
Each template uses CSS custom properties (variables) at the top of the `<style>` block. For example:
```css
:root {
    --primary: #7c3aed;    /* Change this to your brand color */
    --accent: #3b82f6;     /* Secondary accent color */
    --bg-dark: #0f0f1a;    /* Background color */
}
```

### Adding Images
Replace placeholder divs like:
```html
<div class="hero-image">
    <span>Your Product Screenshot</span>
</div>
```
With actual images:
```html
<img src="your-image.jpg" alt="Description" class="hero-image">
```

### Deploying
- **GitHub Pages**: Push to a repo and enable Pages in settings
- **Netlify**: Drag and drop the folder at netlify.com
- **Vercel**: Run `vercel` in the folder
- **Any Web Host**: Upload via FTP or file manager
