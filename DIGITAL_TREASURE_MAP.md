## NAVIGATION RULES

1. **Always dig deeper**: A surface find is never the final destination
2. **Verify the evidence chain**: Search result → Original source → Technical evidence → Current state → Value validation
3. **Check legal safety**: No unauthorized access, credential theft, payment manipulation
4. **Test for repeatability**: Can the discovery be automated? Are there 10+ like it?
5. **Fuse unrelated technologies**: Old + new, small + large, obscure + popular
6. **Follow the money path**: Ensure there's a clear path from value to revenue
7. **Never trust search results without original source verification**
8. **Destroy bad opportunities quickly**: Test demand, competition, cost, distribution, feasibility, legal constraints, copyability
