# بوت تداول بايننس (سبوت)

بوت تداول تلقائي لأزواج السبوت على Binance، باستراتيجية بسيطة وواضحة:

- **شراء:** عندما يكون RSI(14) أقل من 30 (ذروة بيع) والسعر فوق EMA(20) (اتجاه صاعد)
- **بيع:** عندما يكون RSI فوق 70، أو عند ربح +4%، أو عند خسارة -3% (Stop-Loss)
- **وضع تجريبي (Paper) افتراضي:** يشتغل بأسعار حقيقية وفلوس وهمية — افتراضي ومفعّل دائماً
- **سجل كامل:** كل صفقة تُسجل في `trades.csv` وحالة الحساب في `state.json`

## التشغيل

```bash
node src/bot.js
```

### وضع التجربة (مفعل افتراضياً)
شغّل البوت واتركه يراقب. سترى الأسعار وRSI وEMA لحظياً، ويشتري ويبيع بفلوس وهمية في `trades.csv`.

### وضع التداول الحقيقي
افعل هذا **بعد** أن تثق بالاستراتيجية من التجربة:

1. ادخل بايننس → صورة حسابك → **API Management** → Create API Key
2. عند الإنشاء:
   - فعّل صلاحية **Enable Spot & Margin Trading** فقط (ممنوع منعاً باتاً صلاحية السحب Withdrawals)
   - فعّل **Restrict access to trusted IPs only** (أضف IP جهازك) — حماية إضافية
3. ضع المفتاح والسري في `config.json`:
   ```json
   "paperMode": false,
   "apiKey": "مفتاحك هنا",
   "apiSecret": "سريك هنا"
   ```
4. `node src/bot.js`

> **تنبيه:** لا ترسل مفاتيح API لأي شخص، وأعد إنشاءها إذا شككت بتسريبها.

## الإعدادات (config.json)

| الخيار | المعنى | الافتراضي |
|---|---|---|
| `paperMode` | تجريبي أم حقيقي | `true` |
| `paperBalance` | رصيد المحاكاة | `100` |
| `symbol` | زوج التداول | `BNBUSDT` |
| `interval` | الشمعة | `15m` |
| `pollMs` | الفحص كل كذا ملي ثانية | `30000` |
| `buyRsi` / `sellRsi` | عتبات الشراء/البيع | `30` / `70` |
| `takeProfitPct` / `stopLossPct` | الربح/الخسارة المغلقة | `4` / `3` |
| `tradeSizePct` | نسبة الرصيد للصفقة الواحدة | `25` |
| `minNotional` | حد الشراء الأدنى على بايننس | `10` |

## اختبار الاستراتيجية

```bash
node src/test.js            # على BNBUSDT
node src/test.js SOLUSDT 1h # زوج وفاصل آخر
```

## ملاحظات صادقة

- محاكاة الماضي **لا تضمن** أرباح المستقبل — الأسواق متقلبة والاستراتيجيات تنكسر.
- الحد الأدنى للشراء الحقيقي على بايننس ~10 USDT، فمبلغ 5 دولار لا يصلح للتداول الحقيقي — مناسب للتجربة والتعلم فقط.
- هذا مشروع برمجي تعليمي، ليس نصيحة مالية. القرارات والمسؤولية عليك.
