## FORGOTTEN CAPABILITIES (Top 12)

### Tier 1: Algorithmic Breakthroughs
1. **Fast-WaveNet** (tomlepaine/fast-wavenet, 2016): O(2^L)→O(L) optimization for autoregressive models. Still cited in 2026 papers. Modern relevance: applies to ANY causal dilated convolutional network.

2. **PAQ Context Mixing** (Multiple forks): Near-theoretical-optimal compression via 50+ model ensemble. Best compression ratios ever achieved. Modern relevance: LLM context compression market ($10+/M tokens), archival storage.

3. **GraphChi** (GraphChi/graphhi-cpp, 2012): Parallel Sliding Windows for out-of-core graph processing. Process 6.7B edges on single Mac Mini. Modern relevance: NVMe SSDs make single-machine graph processing competitive with clusters.

### Tier 2: Production-Tested Systems
4. **Hank** (LiveRamp/hank, 2010): Distributed KV store with <2 disk seeks per read at 1000:1 data-to-RAM ratio. Used in production with >99.9% availability. Modern relevance: Edge computing, IoT data stores, cold storage analytics.

5. **MegaKV** (pzrq/megakv, 2015): GPU-accelerated KV store. Offloads index operations to GPU. Modern relevance: GPU computing mainstream (CUDA, ROCm), edge GPU available.

6. **BoltDB** (boltdb/bolt, 2013): Pure Go B+tree with ACID transactions, lock-free MVCC. Used by Shopify, Heroku. Modern relevance: Foundation for bbolt (CoreOS), still used in etcd.

### Tier 3: Specialized Capabilities
7. **GecoNet** (Kiddinglife/geconet, 2016): Game-optimized transport protocol (RFC-4960 based). Multihoming, encryption. Modern relevance: WebRTC limitations for gaming, real-time communication needs.

8. **DFP String Matching** (nfsp3k/dfc, 2016): SIMD-optimized string pattern matching at network speed (NSDI 2016 paper). Modern relevance: Network security, DPI, content filtering at line rate.

9. **Aang NLU** (DannyNemer/aang, 2017): A* graph search through parse forests, ~20ms full NLU. Deterministic, auditable. Modern relevance: Compliance-critical applications needing auditable NLU.

10. **Sosistab** (geph-official/sosistab, 2021): Obfuscation + Reed-Solomon FEC + dynamic batching. Used by Geph VPN. Modern relevance: Growing demand for censorship-resistant communication.

11. **dsp.js** (corbanbrook/dsp.js, 2010): Complete DSP library for JavaScript: oscillators, FFT, filters, envelopes, reverb. Pioneer of browser-based audio processing. Modern relevance: WASM compilation, server-side audio, IoT audio.

12. **Pequod** (bryankate/pequod, 2014): Distributed cache with materialized views - cache joins. NSDI 2014 paper. Modern relevance: Real-time analytics, CDN edge caching, streaming joins.
